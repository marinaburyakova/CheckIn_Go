# CheckIn Go - Hotel Booking System

[![React](https://img.shields.io/badge/React-19-blue.svg)](https://reactjs.org/)
[![Vite](https://img.shields.io/badge/Vite-5.0-purple.svg)](https://vitejs.dev/)
[![CSS Modules](https://img.shields.io/badge/CSS-Modules-green.svg)](https://github.com/css-modules/css-modules)
[![License](https://img.shields.io/badge/License-MIT-yellow.svg)](LICENSE)

A modern, feature-rich hotel booking platform built with React 19, Vite, and CSS Modules. Real-time collaboration, dark mode, interactive maps, and seamless booking experience.

![CheckIn Go Screenshot](https://via.placeholder.com/1200x630?text=CheckIn+Go+Screenshot)

## Features

###  Core Features
- **Real-time Hotel Search** - Instant search with autocomplete suggestions
- **Interactive Calendar** - Dynamic pricing visualization, date range selection
- **Advanced Filters** - Filter by price, rating, amenities, property type
- **Sorting Options** - Sort by price, rating, popularity
- **Wishlist** - Save favorite hotels to your personal wishlist
- **Booking System** - Complete booking flow with date & guest selection
- **User Authentication** - Login/Register system (mock, ready for backend integration)
- **Dark/Light Mode** - Beautiful dark theme with glass morphism effects
- **Responsive Design** - Fully responsive across all devices

###  Advanced Features
- **Drag & Drop Map** - Pan and zoom interactive map like Google Maps
- **Smooth Animations** - Framer Motion powered animations
- **Lazy Loading** - Images and components load on demand
- **Local Storage** - Persist user preferences and wishlist
- **Toast Notifications** - Beautiful animated toast messages
